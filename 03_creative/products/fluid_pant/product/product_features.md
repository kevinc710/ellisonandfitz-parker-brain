# Fluid Pant Product Features

## Feature-to-proof map

| Feature | Status | Best visual proof | Claim-safe language | Avoid |
|---|---|---|---|---|
| Pleated micro-stripe texture | **VALIDATED** | Macro crop, directional light, hand interaction | `The pleated texture catches the light.` | Fabric claims not shown or supported by the page |
| Relaxed straight-leg silhouette | **VALIDATED** | Waist-to-hem, low angle, side profile, full stride | `The straight-leg shape is easy to see in motion.` | `Universally flattering` or sizing claims |
| Natural drape | **VALIDATED** visual signature | Walking, turn, wind, step, wide stride | `Look at how the fabric moves when you walk.` | Unsupported stretch, performance, or comfort claims |
| Adjustable drawstring waist | **VALIDATED** | Natural waist detail or waistband reveal | `Adjustable drawstring waist.` | Belt or hardware details not present |
| Lightweight and breathable fabric | **VALIDATED** | Light, natural movement and product page reference | `Lightweight and breathable.` | Temperature-control or athletic-performance promise |
| Machine washable and quick drying | **VALIDATED** | Usually copy or care context, not visual demonstration | `Machine washable and quick drying.` | Maintenance outcome beyond approved facts |
| Color shift under light | **STRONG SIGNAL** | Directional lighting, turn, close crop | `Light changes how the texture reads.` | Invented colorway or altered product color |
| Pocket interaction | **STRONG SIGNAL** | Hand entering pocket while product dominates frame | Visual proof rather than copy | Adding cargo or extra pockets |

## Feature-priority rule

A creative asset should choose one primary feature and one supporting proof. If an asset tries to explain every feature, it will usually make none memorable.

## Copy hierarchy

1. Show the visual feature.
2. Use one factual description only if the feature needs clarification.
3. Add a creator's first-person opinion only when authentic.
4. Never turn a feature into an unsupported universal outcome.

## Live-source rule

Features listed here are stable product facts as of the current live product page. If a product construction changes, update this file before production use.
