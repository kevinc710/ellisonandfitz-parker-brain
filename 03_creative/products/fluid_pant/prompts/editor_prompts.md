# Fluid Pant Editor Prompt Library

## Editor mandate

> Do not edit a generic fashion video. Build a clear reason to look twice at the Fluid Pant.

The pants are always the hero. Every cut must either create curiosity, reveal pleats or texture, prove drape or silhouette, or reinforce the selected product angle.

## Standard edit request

```text
EDIT TYPE: [9:16 paid social / 4:5 static cutdown / organic creator edit]
PRODUCT: Ellison Fluid Pant
STATUS: [VALIDATED FRAMEWORK / STRONG SIGNAL TEST / HYPOTHESIS TEST]
ONE PRODUCT IDEA: [pleats / drape / texture / color shift / silhouette / pocket interaction]
HOOK: [specific first-second moment]
CONTROL OR VARIANT: [state only the variable changing]
REQUIRED PROOF: [walking / full silhouette / macro texture / waistband / pocket]
SETTING: [secondary context]
CTA OR END FRAME: [if approved]
RIGHTS STATUS: [organic only / paid usage approved]
METRIC: [thumb stop / 3-second hold / CTR / CPP / affiliate clicks / other]
```

## Product Discovery edit

```text
Build a 7 to 9 second product-discovery edit. Start with an extreme macro of pleated fabric that is initially difficult to identify. Reveal the waistband or silhouette, then cut to walking. End on a clean wide-leg silhouette. Keep the product dominant. No empty setup shots.
```

## Movement edit

```text
Build a 6 to 8 second movement edit. Start mid-stride from a low angle. Use a wide stride, turn, or walk sequence to make the fabric move. Include one tight product detail, then end on a full silhouette. Cut all dead time. The pant must stay visually dominant.
```

## Texture edit

```text
Build a 6 to 8 second texture edit. Open with a hand touching, brushing, or entering the pocket of the Fluid Pant. Cut to pleated detail under directional light, then show waistband or a second tactile proof. End on a walking silhouette. Avoid face-led or lifestyle-only shots.
```

## Creator-led edit

```text
Use a product-first opening. Allow the creator one concise, natural personal-style observation after the product has appeared. Cut back immediately to movement, texture, or full silhouette. Do not keep the creator talking while the product waits to appear. Do not add claims the creator did not make.
```

## Variant rule

When testing a hook, hold the body edit constant. Change only the first 0.5 to 1.5 seconds. Name the asset using `FLUID_[FRAMEWORK]_[HOOK]_[VARIANT]_v01` and record the changed variable in Testing History.

## Final editor checklist

- [ ] Is the pant the first thing noticed?
- [ ] Does the first second create curiosity or demonstrate a visible differentiator?
- [ ] Does the edit pursue only one product idea?
- [ ] Is the product larger and more memorable than the person or environment?
- [ ] Were generic comfort or lifestyle claims avoided?
- [ ] Is any creator rights status confirmed before paid use?
- [ ] Is the file named, logged, and tagged as Fluid Pant?
