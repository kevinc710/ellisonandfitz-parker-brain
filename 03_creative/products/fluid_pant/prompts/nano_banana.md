# Fluid Pant Nano Banana Static Prompt Library

## Before prompting

Use a current official product image for the selected colorway when product fidelity matters. The model must preserve the pant's relaxed straight-leg silhouette, pleated micro-stripe texture, natural drape, and drawstring waist when visible.

## Required fidelity block

Append this block to every prompt:

```text
Preserve the Ellison Fluid Pant's relaxed straight-leg silhouette, visible pleated micro-stripe texture, natural fabric drape, and adjustable drawstring waist. Do not add cargo pockets, belt loops, zippers, logos, cuffs, denim texture, athletic side stripes, leather, extra hardware, prints, or a different pant shape. Keep the pant visually dominant. No embedded text unless the assignment specifically requests typography.
```

## Static framework: silhouette first

```text
Create a premium but native 4:5 editorial static for the Ellison & Fitz Fluid Pant. Show a style-conscious person mid-stride in a clean architectural setting. Frame from waist to hem so the relaxed straight-leg silhouette and pleated fabric dominate the image. Use directional light to make the texture and natural drape visible. The background is minimal and secondary. Leave clean negative space at the top for optional future copy.

[REQUIRED FIDELITY BLOCK]
```

## Static framework: texture first

```text
Create a 4:5 Fluid Pant product-detail static. Use an extreme macro crop of the pleated micro-stripe fabric with directional light revealing texture and tonal depth. Include a natural hand interaction that lightly brushes or pinches the fabric. The image should feel like product discovery, not a catalog flat lay. The garment should initially be visually intriguing, then recognizable through a small secondary glimpse of silhouette or waistband.

[REQUIRED FIDELITY BLOCK]
```

## Static framework: color-shift first

```text
Create a 4:5 Fluid Pant static where directional light reveals the product's tonal variation and pleated texture. Frame waist to hem or mid-leg so the fabric is the main subject. Use a simple dark or neutral environment to maximize product readability. The image should make the viewer look closer before noticing the full garment construction.

[REQUIRED FIDELITY BLOCK]
```

## Static framework: creator-context first

```text
Create a 4:5 native editorial static for the Ellison Fluid Pant in a creative-work context. The person may be in a rehearsal space, studio, gallery, city street, or minimalist workspace, but the pant must be the first visual read. Show either movement or a clear full silhouette. The context should imply personal style and creative life without showing performance props or the person's face as the main subject.

[REQUIRED FIDELITY BLOCK]
```

## Optional copy directions

Use one short line only, and only when the visual already makes the product readable.

- `LOOK CLOSER`
- `THE PANTS THAT MOVE DIFFERENT`
- `NOT YOUR USUAL PANTS`
- `ONE PIECE. YOUR WAY.`

Do not include price, discount, delivery, universal comfort claims, or unvalidated social-attention claims in the image copy without current approval.

## QA checklist

- [ ] Is the pant the first thing noticed?
- [ ] Is one visual signature unmistakably readable?
- [ ] Does the silhouette remain relaxed and straight-leg?
- [ ] Is the background secondary?
- [ ] Is any text concise and claim-safe?
- [ ] Does the image avoid invented details or colorways?
