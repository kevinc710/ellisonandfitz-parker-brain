# Fluid Pant Visual Test Batch 2

> **Product scope:** Ellison Fluid Pant only. None of these hooks, footage selections, or editing rules may be applied to Tavo Stripe Short, Cassius Knit Polo, Bren Sketch Short, Denzo Knit Pullover, or any future product.

## Purpose

This batch validates product-first visual language before scaling. The first second is the primary testing surface. Each video opens on one Fluid Pant differentiator, then uses only approved GOLD footage to add product proof. Audio is held constant across all eight video assets so that visual hooks and observation time remain the meaningful variables.

## Real-footage static set

Twelve 4:5 real-footage images were extracted from the same Rinat Fluid Pant GOLD library. They contain no copy, fabricated product details, or environment generation.

| Static group | Count | Product proof |
|---|---:|---|
| Extreme pleat / texture | 3 | Pleat construction, micro-stripe texture, and light response |
| Color / light interaction | 3 | Authentic directional-light tonal depth |
| Mid-stride / silhouette | 3 | Relaxed straight-leg proportion and drape |
| Pocket / waistband / tactile detail | 3 | Pocket interaction, adjustable drawstring waist, and tactile construction |

The real-footage static set is the control for subsequent environment tests. It should be evaluated before environment variation, with selected colorway, audience, offer, and placement held stable where possible.

## Environment-test briefs

Eight 4:5 environment briefs are ready for generated static testing after the real-footage control is established: bright white minimal studio; modern glass and stone plaza; clean upscale urban sidewalk; gallery or design interior; hotel or elevated travel corridor; warm minimal residential interior; dark neutral studio with hard directional light; and native phone-camera real-world setting.

Each brief requires the current official Fluid Pant image for the selected colorway. It forbids inventing cargo pockets, belt loops, zippers, logos, cuffs, denim texture, extra hardware, unsupported colorways, or artificial color gradients.

## Measurement order

1. For hook and static ranking, assess **Thumb Stop Rate** first.
2. For video hooks, assess **3-second Hold Rate** second.
3. Assess CTR after a visual treatment earns attention.
4. Assess conversion metrics only after the preceding attention metrics have reached a stable read.

Product-specific creative conclusions require comparable Fluid Pant data. Do not use Tavo Stripe Short, Cassius Knit Polo, Bren Sketch Short, Denzo Knit Pullover, or brand-level observations as proof that a Fluid Pant hook wins.
