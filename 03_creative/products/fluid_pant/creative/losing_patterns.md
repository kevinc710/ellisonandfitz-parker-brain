# Fluid Pant Losing and Deprioritized Patterns

> A losing pattern is not necessarily permanently ineffective. It may be `DEPRIORITIZED`, `HYPOTHESIS`, or `UNTESTED` because it does not currently match the Fluid Pant evidence base. Do not label an approach as failed unless a Fluid Pant-specific test supports that conclusion.

## Current guardrails

| Pattern | Status | Reason | What to do instead |
|---|---|---|---|
| Long talking-head opening before product appears | **DEPRIORITIZED** | The existing product strategy requires the pant to be the first thing noticed and identifies Talking Head as Tier 3. | Show product movement, texture, or silhouette first. Use concise creator dialogue only after the product appears. |
| Founder-led creative as default | **DEPRIORITIZED** | Founder concept is listed as Tier 3 in the current Fluid Pant record. | Use product proof or creator context that keeps pant visibility high. |
| Floating-product visual as default | **DEPRIORITIZED** | Floating Product is listed as Tier 3 and lacks the tactile or movement proof central to the product. | Use hand interaction, drape, texture, or walking. |
| Generic entrepreneur lifestyle | **DEPRIORITIZED** | Entrepreneur Lifestyle is listed as Tier 3 in the product record. | If using a professional context, make it a real product-first styling or movement test. |
| Static pose with no product story | **STRONG SIGNAL** | Static shots are predicted to have lower scroll-stop potential than product movement, texture, or visual novelty. | Add movement, texture, color shift, silhouette, or a visual puzzle. |
| Generic comfort and versatility message | **HYPOTHESIS** | It is not a unique Fluid Pant differentiator and can describe any pant. | Use real product proof and specific first-person experience. |
| Environment-led opening where the pant appears late | **HYPOTHESIS** | The product-first rule is validated; environment is secondary. | Start with product and use the setting only to add context. |
| Cross-product creative borrowing | **PROHIBITED** | Another product's creative result is not Fluid Pant evidence. | Convert outside learning into a labeled Fluid Pant hypothesis and test it. |

## Non-negotiable exclusions

Do not create or approve an asset that:

- Makes a price, shipping, availability, durability, performance, or universal-fit claim without a current, approved source.
- Uses a creator's organic affiliate asset in paid media without written rights.
- Shows the creator, setting, or edit style more clearly than the Fluid Pant.
- Uses an assumed demographic as the creative premise.
- Combines multiple untested angles in a way that makes learning impossible.
- Treats Tavo Shorts, Denver Knit, or another product's result as a Fluid Pant truth.

## How to reconsider a deprioritized pattern

A deprioritized pattern can return only through a defined Fluid Pant test. The brief must state:

1. The exact pattern being tested.
2. The product-first control.
3. The metric that determines whether it advances.
4. The expected learning and the date for review.

Update [Research: Testing History](../research/testing_history.md) with the outcome. Do not remove an existing guardrail based on a hunch.
