# Fluid Pant VA and Team Workflow

## Purpose

This workflow keeps Fluid Pant work consistent across VAs, editors, creators, and AI tools. The goal is not to create more documents. The goal is to make every task start from the same product facts, audience logic, creative rules, and approval boundaries.

## Team roles

| Role | Uses this system for | Must not do |
|---|---|---|
| VA | Candidate research, creator outreach, follow-up, brief distribution, status updates, and content collection | Approve offers, paid-media rights, exception commissions, or product claims independently |
| Creator Program Manager | Candidate approval, UpPromote invitation, creator brief, affiliate activation, and first-post review | Promise paid UGC before internal approval |
| Editor | Static or video assembly, prompt creation, hook testing, and performance logging | Change product truth, offer, or creator rights terms |
| Media Buyer | Test planning, creative naming, ad-level attribution, and feedback to the Learning Log | Use creator assets in paid media without rights verification |
| Growth Lead | Product prioritization, audience hypotheses, creative strategy, offer exceptions, and UGC selection | Leave a major learning undocumented |

## The operating sequence

### 1. Start every Fluid Pant task correctly

Before drafting outreach, prompting AI, assigning an editor task, or briefing a creator:

1. Open the [Fluid Pant Product Knowledge System](README.md).
2. Read the file that matches the task.
3. Check the live product page if a dynamic fact will be mentioned.
4. Work from the assignment brief, not from memory or a past ChatGPT conversation.

### 2. Creator workflow

| Task | VA action | Internal record |
|---|---|---|
| Source a prospect | Add basic public link, visible context, and one product-fit note | Creator Pipeline |
| Send outreach | Use the universal template plus one relevant personalization sentence | Outreach date and message status |
| Screen response | Request social links, samples, audience summary, and affiliate-pilot confirmation | Screening notes and decision |
| Advance prospect | Send approved affiliate offer and UpPromote invite | UpPromote status and unique code or link |
| Send brief | Send only one current Fluid Pant affiliate brief at a time | Brief ID, due date, and owner |
| Review first post | Check product accuracy, product visibility, disclosure, assigned code or link, and published URL | First-post review |
| Escalate to UGC | Request paid usage rights and issue a separate paid UGC brief only after approval | Asset ID and rights status |

### 3. Static or AI creative workflow

1. Select **one visual idea** from the Creative Operating System: pleats, drape, texture, color shift, silhouette, waistband, or pocket interaction.
2. Select a format: 9:16 video, 4:5 static, or 1:1 static.
3. Use the prompt framework. Specify camera, action, product priority, and a secondary setting.
4. Run the pre-publish checklist.
5. Name the asset consistently: `FLUID_[FORMAT]_[ANGLE]_[HOOK]_v01`.
6. Log the asset, test, and result in the designated creative or performance tracker.

### 4. Creator brief workflow

Every Fluid Pant creator brief must include:

- The current live product link.
- One product focus and one creative angle.
- Product-first direction.
- Deliverables, due date, disclosure rule, tag, link, and code instructions.
- A reminder not to state changing price, shipping, or inventory details without checking the product page.
- A clear statement that affiliate organic use does not grant paid-media usage.

## QA checklist for VAs

Before sending a message, brief, or AI prompt, confirm:

- [ ] The candidate or creator personalization comes from a visible, relevant context.
- [ ] The message does not assume age, income, or identity.
- [ ] The product language follows `01_product_truths_and_claims.md`.
- [ ] The brief contains only the approved commercial terms.
- [ ] No paid UGC, performance bonus, or rights promise is implied unless separately approved.
- [ ] The link, code, and current offer are correct.
- [ ] The message has an internal owner and a next action.

## Escalation triggers

Escalate to the Creator Program Manager or Growth Lead when:

- A creator asks for a fixed fee, paid usage, whitelisting, Spark Ads, or an ad-spend bonus.
- A creator requests a rate, discount, or custom code outside the standard affiliate pilot.
- A product claim, shipping statement, or current offer is not clearly supported by the live page.
- A creator's first asset does not make the Fluid Pant visually clear.
- A creator's content performs unusually well or reveals a new audience or creative hypothesis.

## Weekly maintenance

| Day | Minimum action |
|---|---|
| Monday | Review active creator briefs, candidate pipeline, and product page changes. |
| Wednesday | Check content deliveries, product accuracy, rights status, and open follow-ups. |
| Friday | Log creator learnings and creative performance signals. Update the Learning Log if a conclusion is supported. |

## AI handoff instruction

When asking any AI system for Fluid Pant work, provide the relevant file content or the AI Context Pack. Do not expect a model to remember a GitHub link, infer the current strategy, or know which product claims are dynamic.
