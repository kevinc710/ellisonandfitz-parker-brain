# Ellison & Fitz — Parker Brain

This repository is the persistent brand knowledge base ("Parker Brain") for
**Ellison & Fitz** (legal entity: DTC Commerce Group LLC), a Shopify-based
hybrid dropshipping and branded apparel brand.

It is maintained collaboratively by the founders and their AI agents. Content
here should stay current — treat it as living documentation, not a one-time
snapshot.

## Structure

- `01_brand_foundation/` — mission, positioning, audience, product lines
- `02_operations/` — suppliers, fulfillment routing, returns policy, team roles
- `03_creative/` — creative direction, ad formats, brand voice
- `04_growth/` — marketing channels, analytics, growth history
- `05_roadmap/` — open strategic questions and active initiatives

## Maintenance note

Anyone (or any agent) updating this repo should `git pull --rebase` before
editing and commit+push after. Keep entries dated where facts are likely to
change (supplier terms, ad spend figures, SKU counts).
